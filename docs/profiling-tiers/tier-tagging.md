# Tiered profiling: tier tagging for all 21 roles (Phase 1)

**Status: approved 2026-09-24 ("Yes start"), with every §7 decision taken as recommended. Implemented on branch `feat/profiling-tiers` behind `PROFILING_TIERS_ENABLED` (§8). Not yet committed.**

Tags were checked by a script against `origin/main` @ `78ad05e8`, where 15 roles have a pack (Sheet Metal merged in #1693, Industrial Electrician in #1694, then Press #1697, Assembly #1699, Fitter #1701 and QC #1702). The script confirmed that every pack question is tagged exactly once, that this document's tier equals the pack's `min_tier`, each experience gate matches the pack's `ask_if`, each row label matches `trade-resume-map.ts`, and no Easy or Medium row is dropped by the Hard sheet's 10-row budget. The same data is in `tier-tagging.csv`, and the tags themselves now live as `min_tier` in each pack JSON, the source of truth.

## 1. Rules applied

The two §4 examples are the calibration, and both come out exactly as tabled. The rest applies the §4 rule with these readings:

| #      | Rule                                                                                                                                                                                                                                           | Where it comes from                                                                               |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **R1** | Every mandatory item and every experience **tier gate** is **easy**. They decide which later questions are asked and how answers are read, so no tier may drop them. The gate is usually already known from the chat (#1459) and is not shown. | Structural: a gate filtered out leaves every `ask_if` unresolved                                  |
| **R2** | Easy skill fields = the role's **primary machines/software** field(s) plus the field printed in the **headline**. Where these are the same field, Easy has one skill row.                                                                      | §4 wording ("the primary machines/software and the one other field that appears in the headline") |
| **R3** | The **level rung** question (Helper / Operator / Skilled…) is **easy**. It prints in the headline role title ("Welder — Certified Welder").                                                                                                    | `trade-resume-map.ts` notes: the rung is a headline slot                                          |
| **R4** | **Medium**: secondary chips (materials, controllers where they are not the headline, modules, electrodes, coatings, tool steels) and core day-to-day competence (measuring/checks, programming, drawings, operations).                         | §4 Medium                                                                                         |
| **R5** | **Hard**: setting/workholding, tolerance and its equivalents (surface finish, film thickness, capacity, tonnage), advanced capability, specialist work, quality/troubleshooting/defects, sectors, and every never-printed specialist item.     | §4 Hard                                                                                           |
| **R6** | **A row the Hard sheet's 10-row budget would drop for a fully-answered senior cannot be Easy or Medium.** Otherwise a Medium sheet prints a row that disappears on upgrade to Hard. The validator enforces this.                               | Keeps the output monotonic, and "Hard output unchanged" means the budget stays                    |
| **R7** | Untagged = **hard**.                                                                                                                                                                                                                           | §5.1                                                                                              |

Experience gates and tiers are **independent and both apply**. For example, `programming_level` is Medium **and** asked only at 5+ years, so a 2-year turner is never asked it at any tier.
