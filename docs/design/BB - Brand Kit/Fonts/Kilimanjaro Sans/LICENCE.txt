KILIMANJARO SANS — LICENCE RECORD
=================================

The font binaries in this folder (`The Fonts/...`) are a COMMERCIAL typeface.
No licence file shipped with the brand-kit hand-off, so this file records the
terms already on record in the repo rather than restating them from memory.

The shared token layer records the licence as:

    "Nicky Laatz 2022 – All rights reserved"

See `packages/design-tokens/tokens.css` (the `@font-face` block for
"Kilimanjaro Sans" and the header comment that cites the licence).
